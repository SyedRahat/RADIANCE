# RADIANCE

This repository holds project material. Each project has its own folder.

| Folder | Project | Start here |
|---|---|---|
| [`LAM-TVRMS/`](LAM-TVRMS/) | **LAM – TV (Test Vehicle) Request Management System** – A to Z development guide on Microsoft Power Platform, with sample data and PDF versions | [`LAM-TVRMS/README.md`](LAM-TVRMS/README.md) or the single PDF [`LAM-TVRMS/pdf/LAM-TVRMS-Complete-Guide.pdf`](LAM-TVRMS/pdf/LAM-TVRMS-Complete-Guide.pdf) |

## What is inside `LAM-TVRMS/`

| Sub-folder | What it has |
|---|---|
| `README.md` | Project summary and the order to read the guides |
| `docs/` | 14 guides (00 to 13) – from "Is the PPT enough?" to the end-to-end use case |
| `sample-data/` | 10 CSV files with test data to import into Dataverse |
| `pdf/` | The same guides and data as PDF files, plus one complete guide PDF |
| `tools/pdf-export/` | The script that creates the PDFs again after a guide changes |
